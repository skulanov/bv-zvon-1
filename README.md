# Электронная звонница

Веб-приложение, имитирующее игру на колоколах — с помощью клавиатуры, мыши
или касания экрана.

Трапеции на странице изображают колокола, расположенные в реальной геометрии
развеса на звоннице (благовестники, подзвоны, зазвоны). Буква на колоколе —
клавиша клавиатуры, при нажатии которой звучит сэмпл этого колокола.

## Управление

| Группа | Клавиши |
| --- | --- |
| Благовестники | V, B, N, M |
| Подзвоны | Q, W, E, A, S, D, X, Z, C |
| Зазвоны | I, O, P |

Клавиши определяются по физическому положению на клавиатуре, поэтому
раскладку (русскую или латинскую) переключать не нужно.

## Запуск

Проще всего поднять любой статический сервер в папке проекта:

```
python3 -m http.server
```

и открыть <http://localhost:8000>. Файл `index.html` можно открыть и напрямую,
двойным щелчком — тогда звук воспроизводится через запасной механизм `<audio>`.

## Как устроено

- `index.html` — разметка: сцена и 16 колоколов с атрибутами `data-note`
- `style.css` — оформление и развес колоколов. Все координаты заданы в единой
  сетке 1330 × 900 условных единиц; размер единицы вычисляется из размеров
  окна, поэтому вся картина масштабируется целиком, а взаимное расположение
  колоколов не меняется
- `index.js` — воспроизведение звука и обработка клавиатуры, мыши и касаний.
  Основной путь — Web Audio: сэмплы декодируются один раз, удары звучат без
  задержки и накладываются друг на друга. Если Web Audio недоступен,
  используется запасной путь на `<audio>`
- `snd3/` — mp3-сэмплы звучания колоколов
