# Электронная звонница

Веб-приложение, имитирующее игру на колоколах — с помощью клавиатуры или мыши.

Трапеции на странице изображают колокола, расположенные в реальной геометрии
развеса на звоннице (благовестники, подзвоны, зазвоны). Буква на колоколе —
клавиша клавиатуры, при нажатии которой (или клике мышью) звучит сэмпл этого
колокола.

## Запуск

Откройте `index.html` в браузере (звук работает при локальном запуске через
любой статический веб-сервер, например `python3 -m http.server`).

## Структура

- `index.html` — разметка колоколов
- `style.css` — стили и геометрия развеса
- `index.js` — обработка клавиатуры/мыши и воспроизведение звука
- `snd3/` — mp3-сэмплы звучания колоколов
